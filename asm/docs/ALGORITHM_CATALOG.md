# Conventional ASM Algorithm Catalog

- Boolean gates and adder arithmetic
- 20-bit add/subtract/multiply-low
- Binary search and checksum
- Euclidean GCD
- 20-byte record read/write/validation
- BST search
- Graph breadth-first traversal
- File open/read/write/close interface
- Update transaction with dependency/hash verification and rollback

Routines are intentionally small so they can be lowered to the concrete Model K opcode set.
