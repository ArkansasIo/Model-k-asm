# Calculus and Algorithmic Models

Discrete state recurrence: x_(n+1)=F(x_n,p_n).

Continuous performance model: dx/dt=F(x,t).

Binary search uses mid=floor((low+high)/2) and is O(log n).

Checksum and SHA-256 processing are O(n) in bytes.

For independent operation failure probabilities p_i: P(at least one failure)=1-product(1-p_i).
