# Model QK Project Identity

## Name

**Model QK**

## Relationship to Aethernox

**Aethernox Paradox Core** is the broader research architecture and **Model QK** is the current computer-system/project name.

## Architecture

Model QK combines:
- classical 8-bit Model K compatibility hardware,
- Aethernox v2 64-bit logical-data research,
- modern memory backends,
- conventional assembly and native reference software,
- a separate quantum control/programming research layer.

The architecture is hybrid at the system level; it does not imply that classical memory stores qubits or that the classical CPU is itself a quantum processor.

## Compatibility

The model_k, mk_, and MK identifiers are legacy namespaces. They remain in source where changing them would create an ABI, RTL, build, or file-format break. A future Model QK ABI migration can introduce qk_ identifiers alongside explicit compatibility shims.
